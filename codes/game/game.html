Circle Rules Slide Show

半径与直径

直径始终等于 2 倍半径，记作 d = 2r。

周长公式

圆周长 C = 2πr，也可以写成 C = πd。

面积公式

圆面积 A = πr²，注意单位是平方单位。

切线性质

切线与过切点的半径互相垂直，夹角为 90°。
